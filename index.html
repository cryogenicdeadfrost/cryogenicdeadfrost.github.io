I'm an M1 Informatics student at Université Grenoble Alpes & Grenoble INP - Ensimag in France. I don't do hype-driven web frameworks or corporate slide decks; I care about systems that don't segfault when the network breaks and cryptographic primitives that survive hardware noise.

Synchronous, zero-trust multi-camera stream aggregator. Utilizes libsrtp for authenticated end-to-end payload encryption, OpenSSL TLS session controls over libwebsockets, and isolated POSIX thread pools per ingest pipeline to eliminate jitter across asynchronous capture devices.

High-performance native Bluetooth device orchestration suite. Provides safe Rust wrappers and zero-cost FFI bindings over raw Win32 Bluetooth API endpoints, exposing reliable socket pairing, automated service discovery, and low-latency serial communication without legacy driver crashes.

NexLog
C/C++ · Raw Sockets
High-throughput network flow sensor operating on raw AF_PACKET sockets. Capable of parsing 100,000+ packets/sec with zero copy, computing real-time Shannon entropy over TCP payload windows to catch encrypted C2 beacons and automated scanning attacks inline.
pcap entropy 100k-pps

DirectoryNator
C · Syscalls · POSIX
Sub-millisecond directory walker and recursive indexer written in pure C. Minimizes kernel transition overhead through direct getdents64 syscalls, branch-predicted path buffers, and lock-free thread queues, outperforming standard recursive traversal utilities across massive directory trees.
filesystem io syscalls
Syscalls→ Scanner→ Index→ Output
"Because waiting for standard recursive tools is a waste of CPU cycles."
